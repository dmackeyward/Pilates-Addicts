# Pilates Addicts

A small interactive knowledge base for Pilates instructors.

## Project structure

- `index.html` — interactive entry point for the website
- `styles.css` — page styling
- `script.js` — interactive navigation logic
- `docs/` — document library
  - `home/` — studio overview, teaching philosophy, and AI skill overview
  - `exercises/` — exercise series by category
  - `spring-settings/` — starter guidance for introduction, high-yellow, yellow-green, green, and red spring choices
  - `class-plans/` — sample lesson plans
  - `method/` — core biomechanical principles
  - `assessments/` — exam and evaluation notes
