Real AI Skill vs. Static Helper

A true AI skill is not a fixed form or simple rule engine. It is a component that sends your intent to a language model, receives a customized plan, and surfaces that result in a usable format.

How a real AI skill works

  • Collect the user’s teaching intent, session goals, client level, and desired duration.
  • Format that information into a prompt that an AI model can understand.
  • Send the prompt to an AI service such as OpenAI, OpenRouter, or another model provider.
  • Receive a generated lesson plan, then present it clearly in the interface.

Why this matters for test-plan generation

Generating a good lesson plan requires thought, context, and adaptation. A true AI skill can propose exercises, sequencing, progressions, and cues aligned to the student’s needs, rather than only selecting from a fixed list.

What this repo currently has

The app currently hosts a content library and HTML pages. The AI skill would be a separate integration layer: a provider module, a prompt builder, and a UI flow that sends requests to an AI model.

Next step

To make this real, the next implementation would be:

  1. Define the AI prompt and output format.
  2. Add an AI provider module that connects to a model API.
  3. Build the UI to gather lesson goals and display generated plans.
