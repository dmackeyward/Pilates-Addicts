Introduction

Use spring settings as a simple progression from more support to more challenge.

Spring colours are not universal, so it is more helpful to think in terms of relative tension rather than the colour name alone. A simple framework is:

  • Light or supportive resistance for foundational movement, mobility, and early strength work.
  • Medium resistance for balanced, controlled strength and full-body flow.
  • Stronger resistance for more demanding work where the client can maintain control and precision.

Starter framework

  • Start with 1 Yellow spring on the low peg for the gentlest, most supportive option.
  • Move to 1 Yellow + 1 Green when a client is ready for a little more resistance.
  • Use 2 Green springs for a balanced middle ground in many reformer sessions.
  • Choose 1 Red spring when the client is ready for stronger, more demanding work.

If your studio uses different colours, match the same relative tension level rather than the colour name. The key is always to choose a setting that allows the client to move with control, breath, and good alignment.
