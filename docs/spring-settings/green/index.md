# Exercises using 2 Green Springs

Use 2 Green springs for balanced, intermediate resistance and a steady level of challenge. In other studios this may be described as a medium setting, but the purpose is the same: a useful middle ground between support and stronger resistance.

## Good fits

- Full-body flow work
- Moderate strength and control
- Progressions for clients ready for more challenge

These settings are a strong middle-ground option for many reformer sessions.
